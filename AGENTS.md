# Project: Research Paper Recommender

Two-tower neural architecture for recommending papers based on citations.
- `scripts/models/` — model definitions (two_tower.py etc)
- Python, PyTorch (confirm/adjust)

## Conventions
- Use type hints on all functions
- Tests live in `tests/`, run with `pytest`
- Don't modify files in `data/raw/` — read-only source data

## Style
- Prefer explicit over clever
- No premature optimization
